## 1. 形态

自租云主机，单机 + SQLite 单库。四个服务 + 一个存储（架构文档第 4 节）：

| 模块 | 职责 |
|---|---|
| 接入 | 邀请码、学生登记、token 签发 |
| 知识库 | 上传、解析 / 切分 / 索引，保留出处元数据 |
| 检索 | 问题 → 片段 + 出处（**标准答案与题库不在此通道返回**） |
| 记录 | 事件存档、期末导出 |
| 存储 | SQLite 单库（sqlite-vec 向量索引 + FTS5 关键词索引） |
