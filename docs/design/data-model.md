## 1. 数据归属（先看这张表）

架构文档第 2 节定的边界，**这是硬约束，不是建议**：

| 数据 | 存在哪 | 依据 |
|---|---|---|
| 会话记录（JSONL） | 仅本地 | |
| 项目代码 | 仅本地 | |
| 课程 token | 仅本地 | |
| 权限配置 | 仅本地 | |
| 审计日志 | 仅本地 | |
| 课程知识库（教材、课件） | 仅服务端 | 老师更新立刻生效 |
| **标准答案、题库** | **仅服务端，不落学生盘** | 需求硬规矩 4 |
| 使用记录 | 仅服务端 | |
| 学生提问内容 + 检索片段 | **直连模型供应商**，服务端不可见 | ADR：学生自己的 key |

**一句话**：本地翻遍磁盘也找不到标准答案。

## 2. 本地实体

### 2.1 会话（session）

- 存储：JSONL，按课程工作区目录隔离
- 结构：pi 的 SessionManager 树结构（`id` / `parentId` 链接，支持原地分支）
- 【待填】我们是否要在里面加自己的扩展条目（`pi.appendEntry(customType, data)`）

参考：`packages/coding-agent/docs/session-format.md`

### 2.2 审计日志【待填字段】

| 字段 | 类型 | 说明 |
|---|---|---|
| 时间 | | |
| 会话 / 子代理 | | `actor` |
| 工具 + 参数 | | |
| 判定结果 | | allow / deny / ask→? |
| 判定来源 | | 白名单 / 黑名单 / 灰区判官 / 档位 |
| 人类决策 | | 允许 / 拒绝 / 超时 |
| 【待填】 | | |

参考实现：`examples/extensions/tool-override.ts:47-60`

### 2.3 配置【待填】

- 权限档位（三档）
- API key（学生自己的）

- 工作区路径

## 3. 服务端实体

| 实体 | 说明 | 关键字段 |
|---|---|---|
| 课程 | 一门课一个独立知识库与检索空间 | 【待填】 |
| 学生 | 邀请码激活后登记 | 姓名、学号 |
| 资料 | 老师上传的教材 / 课件 | 文件名、格式、处理状态 |
| 片段（索引） | 切分后的检索单元 | 文本、**出处元数据（文件名 + 页码）**、向量 |
| 记录 | 提问 / 反馈 / 拦截事件 | 【待填】 |
| 标准答案 / 题库 | **只存这里** | 【待填】 |
