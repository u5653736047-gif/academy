# academy

**课程 Agent 助教** —— 给编程课学生的本地 AI 助教。

一句话说清它是干什么的：一个装在学生电脑上的 coding agent，能直接读他的代码、跑他的代码、把问题修好；解释问题的时候，引用课程资料（教材、课件）作为依据。

底座是 [pi](https://pi.dev)。

## 三条要守住的原则

1. **不替老师打分。** 评分永远是人的事。
2. **标准答案、题库只存服务端，不落学生磁盘。**
3. **agent 对学生机器的每个动作全部可见、可追溯。** 权限档位决定"要不要先问"，不决定"要不要告诉你"。
